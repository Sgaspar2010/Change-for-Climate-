# ChangeForClimate*
A technological and environmentally-related project which aims to raise awarness not only of climate change but of specific actions that can be done by people who are both junior and senior actors of change related to it. The maxim is "Change for Climate [against Climate Change]". Additionally, environmental news and patterns will probably be included. Many updates will be released soon! 🚀🌠

Previous demo: https://changeforclimate.netlify.app/
New demo: https://changeforclimate.web.app/

The website is developed with HTML, CSS, JS and Firebase. Many stuff are still coming! :)
